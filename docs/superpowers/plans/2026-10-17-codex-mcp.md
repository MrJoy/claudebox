# kindex and Linear under AGENT=codex Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give `AGENT=codex` passes the read-only kindex snapshot and Linear's MCP server, at parity with the Claude arm, without any credential reaching Codex's environment or argv.

**Architecture:** The entrypoint writes the Linear and Voyage keys to a mode-700 directory and unsets them. A new root-owned stdlib module, `reviewer/codex_mcp.py`, builds the `-c mcp_servers.*` flags and doubles as the two helpers Codex runs: a kin-mcp exec wrapper and Linear's `http_headers_helper`. `main()` hands those flags to `Supervisor` in the existing `mcp_args` field, and `codex_pass.build_argv` splices them into every pass.

**Tech Stack:** bash (entrypoint), Python 3.11 stdlib (supervisor), codex-cli 0.162.1.

**Spec:** `docs/superpowers/specs/2026-10-16-codex-mcp-design.md`

## Global Constraints

- Standard library only in `reviewer/`; no pip dependency.
- No credential on any `codex` argv, and none in the environment `codex` is started with. Never use `env_vars` or `bearer_token_env_var`.
- The helpers live in `reviewer/`, whose `COPY` line in the `Dockerfile` has no `--chown`. Do not add one, and do not move the helpers anywhere reviewer-writable.
- The key directory must be outside `$CODEX_HOME` (that volume outlives the container).
- kindex server: `enabled_tools` = `sorted(kindex_tools.READ_TOOLS)`, `required = true`.
- Linear server: `url = "https://mcp.linear.app/mcp"`, no tool filter, not required.
- Every `-c` value is valid TOML, built through `codex_pass.toml_string` or the array builder from Task 1.
- `codex_pass.build_argv` keeps `--strict-config` and `--ignore-user-config` on every pass, and the MCP flags come before the `--`.
- `claudebox.sh` stays bash 3.2-safe (this plan does not touch it).
- Container profile name `claudebox` comes from `graph_snapshot.CONTAINER_PROFILE`, not a new literal.

## Review Focus

- A key value containing spaces, quotes or a trailing newline from the env file: the helper must send it byte-for-byte, minus one trailing newline at most. Task 2 pins it.
- A helper path or key directory containing whitespace: Codex splits `http_headers_helper` on spaces, so `build_args` must refuse it with `ConfigError`, not emit a broken command. Task 2 pins it.
- A restart after a run that had a Linear key, now without one: the stale `linear.key` must be gone and the server absent. Task 5 pins it.
- `VOYAGE_API_KEY` set with no kindex store: nothing written, the existing "ignoring it" line still logs. Task 5 pins it.
- An empty key file (operator wrote `LINEAR_API_KEY=`): the entrypoint writes no file for an empty value, and `linear-headers` exits non-zero on an empty file anyway. Tasks 2 and 5 pin both halves.

def flags(args):
    """{key: value} from a list of -c key=value pairs."""
    pairs = [args[i + 1] for i in range(0, len(args), 2)]
    assert all(args[i] == "-c" for i in range(0, len(args), 2))
    return dict(p.split("=", 1) for p in pairs)
